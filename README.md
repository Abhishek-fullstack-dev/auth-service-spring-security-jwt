# Auth Service – Spring Security + JWT

## Overview
This is a Spring Boot-based authentication microservice that provides secure user authentication using JWT (JSON Web Tokens).

## Tech Stack
- Java
- Spring Boot
- Spring Security
- JWT
- Maven

## Features
- User Registration
- User Login
- JWT Token Generation
- JWT Validation Filter
- Role-based Authorization
- Stateless Authentication

## Architecture
This service is designed to be used in a microservices architecture where authentication is handled centrally.

## Endpoints
- POST /auth/register
- POST /auth/login

## How to Run
1. Clone the repository
2. Run `mvn clean install`
3. Start using `mvn spring-boot:run`
